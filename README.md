# FTL Multiplayer — client downloads

This repository exists to host the **public download files** for the FTL
Multiplayer client. There is no source code here.

## Download

Get the latest build from **[ftlmultiplayer.com/download](https://ftlmultiplayer.com/download)**,
which picks the right file for your operating system automatically.

If you would rather pick manually, every build is attached to the
[Releases](../../releases) page — Windows, macOS and Linux.

## What you need

FTL Multiplayer runs on top of your own copy of the game. You need
[FTL: Faster Than Light](https://store.steampowered.com/app/212680/) on Steam,
and you sign in with Steam so ownership can be verified. No game files are
redistributed here and nothing is cracked — the client reads your existing
installation and leaves your single-player saves and achievements alone.

## Issues and discussion

Bug reports and feature requests belong on the main project, not here. This
repository is only a download host, and issues are disabled.
